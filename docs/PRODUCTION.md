# دفتر الإنتاج والمراجعة

## المواصفات

- المدة: **42.000 ثانية**، 1260 إطاراً.
- الصورة: **1920×1080**، 16:9، 30fps، ألوان BT.709.
- التصدير: MP4 / H.264 / yuv420p / CRF 18.
- الصوت: AAC stereo، والمصدر WAV 48kHz / 16-bit.
- اللغات: العربية أساساً، والإنجليزية كعنصر جرافيكي مساعد.
- كل الرسوم متجهة أو DOM داخل Remotion؛ النسيج الخلفي PNG ثابت مولّد ببذرة ثابتة.

## التايملاين

مدة كل مشهد تشمل نصف ثانية للانتقال الذي يليه. لذلك مجموع مدد المشاهد 1335 إطاراً، ناقص 5×15 إطار تداخل = **1260 إطاراً**.

| المشهد | البداية | مدة المصدر | النهاية على التايملاين الرئيسي |
|---|---:|---:|---:|
| Spark | 0 | 180 | 180 |
| Understand | 165 | 210 | 375 |
| Build | 360 | 240 | 600 |
| Craft | 585 | 240 | 825 |
| Deliver | 810 | 210 | 1020 |
| Together | 1005 | 255 | 1260 |

كل فصل مسجل أيضاً كـComposition مستقل في Remotion Studio لتسهيل المراجعة والتعديل. الانتقالات: editorial wipe مخصص بالاتجاهين، وslide عمودي واحد قبل فصل التصميم.

## قرارات الحركة

- العناوين: قناع سطري، 22–27 إطاراً، مع فواصل 6–8 إطارات.
- العناصر الثانوية: spring بلا ارتداد مبالغ فيه، مع تأخير 7–12 إطاراً.
- المدار: حركة مستمرة بطيئة تعطي عمقاً دون منافسة النص.
- الانتقالات: نصف ثانية مع حافة لونية؛ لا فلاش أبيض.
- الخاتمة: تستقر العناصر وتبقى الدعوة واضحة لعدة ثوانٍ.
- الصوت: 120 BPM؛ مواضع القطع 0، 5.5، 12، 19.5، 27، 33.5 ثانية.

## مراجعة فعلية

`scripts/qa.ts` يرسل إطارات مختارة إلى محرك تصدير Remotion نفسه، وليس إلى تقريب CSS في واجهة مختلفة. يراجع البداية، الاستقرار، والانتقالات، إضافة إلى الفصل الأخير.

```bash
npx tsx scripts/qa.ts
npm run check
npm test
```

اللقطات المؤقتة تظهر في `qa/` وهي مستبعدة من Git. تقرير الإنتاج النهائي موجود في `deliverables/quality-report.json`.

أثناء المراجعة اكتشفنا وأصلحنا:

1. عدم توريث `currentColor` إلى SVG داخل عنصر صورة: أصبحت الأيقونات مسارات SVG داخلية مع لون صريح، مع إبقاء ملفات SVG الأصلية في `public/icons/`.
2. اختلاف اسم Node.js المختصر عن slug الخاص بـSimple Icons: أضفنا ربطاً صريحاً إلى `nodedotjs`.
3. بقاء قناع CSS عند نهاية الانتقال المركّب: يُلغى القناع عند الوصول إلى الاستقرار حتى لا تختفي المشاهد التالية.
4. ارتفاع قناع الخط العربي: زيد إلى 1.38 حتى لا تُقص التشكيلات أو النزول تحت السطر.

## إعادة الإنتاج من الصفر

```bash
npm ci
node scripts/sync-assets.mjs
python3 -m pip install numpy       # داخل بيئة Python مناسبة
python3 scripts/generate_audio.py
npm run check
npm test
npm run render                    # أو render:standard مع متصفح موجود
```

لا يلزم تنفيذ هذه الخطوات لمشاهدة MP4 المسلّم. الخطوط والصوت والأيقونات موجودة بالفعل في المستودع.

## نشر المعاينة

`npm run dev` يشغّل Vite على `0.0.0.0:3000`. مسارات الفيديو نسبية، لذلك تعمل الواجهة خلف وكيل المعاينة بدون الاتصال بـlocalhost من متصفح المستخدم. يسمح الإعداد بنطاقات `.e2b.app`.

`npm run build` (أو `npm run build:review`) ينتج نسخة ثابتة في `build-review/` مع نسخ ملفات التسليم. هذا يحافظ أيضاً على توافق أمر البناء مع workflows Firebase الموجودة، دون تغيير وجهة النشر الأصلية. هذا المجلد تشغيلي ومستبعد من Git. إعداد Firebase القديم و`dist/` لم يتغيرا، ولا يقوم هذا المشروع بالنشر إلى Firebase تلقائياً.
